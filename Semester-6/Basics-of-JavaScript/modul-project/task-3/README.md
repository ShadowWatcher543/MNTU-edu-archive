# Модульна контрольна робота — Завдання 3

Це рішення третього практичного завдання підсумкової модульної роботи.

## Опис завдання
Реалізуйте функцію `createApiClient(baseUrl)`, яка використовує замикання для зберігання `baseUrl` та лічильника запитів. Вона повертає об'єкт з методами:
`get(path) `— асинхронний метод, що виконує  
`fetch(baseUrl + path)` , повертає розпарсений JSON; у разі помилки повертає  `{ error: "Запит не вдався" }`

Кожен виклик збільшує лічильник запитів.
`getRequestCount()` — повертає кількість виконаних запитів. Використайте async/await , try...catch та замикання для приватного лічильника.


## Приклади використання та результати
Для перевірки логіки використовуються два демонстраційні виклики в консолі:
```js
const api = createApiClient("https://jsonplaceholder.typicode.com");
const user = await api.get("/users/1"); // об'єкт користувача
const posts = await api.get("/posts"); // масив постів

console.log(api.getRequestCount())
// 2
```

## Як запустити
1. Переконайтеся, що в системі встановлено npm та Node.js.
2. Скопіюйте директорію завдання.
3. Виконай команди в терміналі в директорії проєкту:
```Bash
npm run dev
```
