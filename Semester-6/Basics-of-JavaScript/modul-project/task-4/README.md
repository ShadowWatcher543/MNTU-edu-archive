# Модульна контрольна робота — завдання 4

Це рішення четвертого практичного завдання підсумкової модульної роботи.

## Опис завдання
Створіть клас TodoList для керування списком завдань та підключіть його до сторінки.
1. Клас Task з полями id , text , done (за замовчуванням false ) та методом toggle() , що інвертує done .
2. Клас TodoList з методами:
   add(text) — створює нову Task з унікальним id і додає до списку
   remove(id) — видаляє завдання за id
   getActive() — повертає масив незавершених завдань
3. JavaScript-код, що при натисканні кнопки \#addBtn бере текст з `<input id="taskInput">`, додає завдання через TodoList , рендерить список у
   `<ul id="taskList">` , а кліком по елементу списку перемикає його стан
   done (використати делегування подій).
