# Модульна контрольна робота — Завдання 1

Це рішення першого практичного завдання підсумкової модульної роботи.

## Опис завдання
Реалізовано функцію `summarizeNumbers(numbers)`, яка приймає масив чисел будь-якої довжини та повертає об'єкт зі зведеною статистикою.

Функція розраховує такі метрики:
* `count` — загальна кількість елементів у масиві.
* `sum` — арифметична сума всіх числових значень.
* `evenCount` — кількість парних чисел серед елементів.
* `max` — максимальне значення в масиві.
* `category` — текстова категорія масиву на основі розрахованої суми чисел:
    * `"empty"` — якщо передано порожній масив.
    * `"positive"` — якщо фінальна сума елементів більша за нуль.
    * `"non-positive"` — в усіх інших випадках (сума менша або дорівнює нулю).

## Приклади використання та результати
Для перевірки логіки використовуються два демонстраційні виклики в консолі:
```javascript
console.log(summarizeNumbers([4, 7, 2, 9]));
// { count: 4, sum: 22, evenCount: 2, max: 9, category: "positive" }

console.log(summarizeNumbers([]));
// { count: 0, sum: 0, evenCount: 0, max: undefined, category: "empty" }
```
