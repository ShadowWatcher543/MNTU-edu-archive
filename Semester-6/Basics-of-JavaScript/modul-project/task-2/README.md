# Модульна контрольна робота — Завдання 2

Це рішення другого практичного завдання підсумкової модульної роботи.

## Опис завдання
Напишіть функцію processProducts(products), 
яка приймає масив товарів і повертає об'єкт. 
Кожен товар:

`{name: "Чай", price: 50, inStock: true}`

Функція повинна повернути:
* available — масив назв товарів, що є в наявності ( inStock === true )
* totalPrice — сума цін усіх товарів у наявності (використати reduce )
* cheapest — назва найдешевшого товару серед наявних
* priceList — масив рядків виду "Чай — 50 грн" для всіх товарів
(використати map) 


## Приклади використання та результати
Для перевірки логіки використовуються два демонстраційні виклики в консолі:
```js
const products = [
    { name: "Чай", price: 50, inStock: true },
    { name: "Кава", price: 120, inStock: false },
    { name: "Цукор", price: 30, inStock: true }
];

console.log(processProducts(products))
// {
// available: ["Чай", "Цукор"],
// totalPrice: 80,
// cheapest: "Цукор",
// priceList: ["Чай — 50 грн", "Кава — 120 грн", "Цукор — 30 грн"]
// }
```

## Як запустити
1. Переконайтеся, що в системі встановлено npm та Node.js.
2. Скопіюйте директорію завдання.
3. Виконай команди в терміналі в директорії проєкту:
```Bash
npm run dev
```
