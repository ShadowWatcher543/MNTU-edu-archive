## Опис реалізованого функціоналу

Проєкт демонструє принципи функціонального реактивного програмування (FRP), чистоти функцій та імутабельності даних без використання зовнішніх бібліотек (типу RxJS).

### 1. Реактивні обчислення та HOF-оператори
* **`Observable<T>`** — базовий клас потоку даних, що реалізує патерн спостерігача.
* **`map(fn)`** — функція вищого порядку, яка трансформує елементи всередині потоку. Використовує вбудований синтаксис `.map()`.
* **`filter(fn)`** — HOF-оператор, який фільтрує події потоку за предикатом. Використовує `.filter()`.
* **`debounce(delay)`** — оператор контролю частоти подій, який запобігає перевантаженню процесора під час живого введення тексту розробником.

### 2. Функціональне програмування (FP)
* **Композиція (`compose`)** — чиста функція, яка з'єднує кілька трансформацій в один конвеєр (справа наліво). Поєднує фільтрацію, перетворення в HTML-масив за допомогою `.map()` та згортку масиву в один рядок через `.reduce()`.
* **Каррінг (`filterByQuery`)** — функція часткового застосування, яка приймає рядок пошуку, замикає його в пам'яті й повертає нову чисту функцію для фільтрації масиву об'єктів.
