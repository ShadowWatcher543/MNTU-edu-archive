# Social Media Profile Management System

Практична робота з курсу "Основи JavaScript/TypeScript" (Варіант №10).
Проєкт реалізує об'єктну модель профілів користувачів соціальної мережі, систему підписок/взаємозв'язків та алгоритм генерації стрічки новин (Feed) за допомогою чистої логіки та базових циклів перебору елементів.

## Структури даних

Проєкт побудований на трьох основних логічних рівнях взаємодії об'єктів:

### 1. `Post` (Об'єкт поста)
Представляє одиницю контенту, створену користувачем.
* `postId: string` — унікальний ідентифікатор публікації.
* `content: string` — текстовий вміст поста.
* `createdAt: Date` — дата та час створення публікації.

### 2. `Profile` (Об'єкт профілю)
Містить особисті дані користувача та методи локальної взаємодії.
* **Властивості:** `userId`, `username`, `bio`, `avatar`, `followers[]`, `following[]`, `posts[]`.
* **Геттери:** * `followerCount` — кількість підписників.
    * `followingCount` — кількість людей, на яких підписаний користувач.
    * `postCount` — загальна кількість опублікованих постів.
* **Методи:** `follow(userId)`, `unfollow(userId)`, `addPost(id, content)`, `getPosts()`.

### 3. `ProfileManager` & `Social Features`
Глобальний менеджер, який виступає в ролі бази даних та реалізує складні алгоритми взаємодії між профілями:
* `createProfile(data)` / `getProfile(userId)` / `deleteProfile(userId)` — CRUD операції.
* `updateProfile(userId, data)` — оновлення даних профілю з використанням **деструктуризації**.
* `searchProfiles(query)` — ручний пошук профілів без урахування регістру літер.
* `getSuggestedProfiles(userId)` — алгоритм рекомендацій нових друзів.
* `getMutualFollowers(userId1, userId2)` — знаходження спільних підписок.
* `getFollowersNotFollowingBack(userId)` — пошук не взаємних підписок.
* `getUserFeed(userId)` — алгоритм збору та **сортування бульбашкою** публікацій відстежуваних користувачів за часом (від найновіших).

##  Технічні особливості реалізації

* **Чиста алгоритмічна логіка:** Всі операції пошуку, фільтрації, перевірки дублікатів та сортування стрічки реалізовані вручну через класичні цикли `for` та умовні оператори `if` без високорівневих методів масивів на кшталт `.map()`, `.filter()`, `.sort()`, чи об'єктів `Set`.
* **Контекст `this`:** Контекст виконання суворо контролюється всередині методів об'єктів для динамічного доступу до їхніх внутрішніх масивів.
